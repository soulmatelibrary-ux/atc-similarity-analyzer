항공 호출부호 유사도 레벨 (ICAO 기준)

LEVEL 5 - 고위험 (Critical) 범위: 90 ~ 100점
레벨 점수 규칙명 상세 탐지 로직
5-1 97~100 항공사 유사
+ 숫자 동일		 항공사 코드 유사(전치/샌드위치) + 숫자 부분이 100% 동일
예: KAL123 vs KLA123
5-2 94~97 동일 항공사
+ Suffix 3		 같은 항공사 + 마지막 3자리 숫자 일치
예: KAL1234 vs KAL7234
5-3 91~94 동일 항공사
+ 시각 유사		 같은 항공사 + 숫자 전체가 시각적 혼동 패턴으로 구성
예: 0/O, 1/I/L, 5/S 혼동
LEVEL 4 - 중위험 (Caution) 범위: 65 ~ 89점
레벨 점수 규칙명 상세 탐지 로직
4-1 85~89 숫자 위치
바뀜		 숫자 구성은 같으나 순서가 하나만 바뀜
예: KAL123 vs KAL132
4-2 82~85 양끝 일치
+ 가운데 유사		 같은 항공사 + 첫/끝 숫자 동일 + 가운데 시각적 유사
예: KAL103 vs KAL183 (0/8 혼동)
4-3 75~82 한 자리
혼동		 한 자리만 다르되, 청각적/시각적 혼동 쌍에 해당
예: KAL123 vs KAL125 (3→5), KAL183 vs KAL123 (8→3)
4-4 70~75 항공사 유사
+ 숫자 유사		 항공사 유사(전치/샌드위치) + 숫자가 청각/시각 혼동 패턴에 해당
4-5 65~72 다른 항공사
+ 숫자 동일		 항공사는 다르나 숫자 부분이 완전히 동일
예: KAL123 vs AAR123 (항공사 상이하므로 혼동 가능성↓)
LEVEL 3 - 저위험 (Notice) 범위: 50 ~ 64점
레벨 점수 규칙명 상세 탐지 로직
3-1 50~64 Leading
Zero 차이		 수치적 값은 동일하나 표기만 다른 경우
예: KAL123 vs KAL0123
혼동 패턴 기준 (ICAO Doc 9432, EUROCONTROL)
청각적 혼동: (1↔9), (5↔9), (2↔3) | (M↔N), (S↔F)
→ 교신 시 무전기 노이즈 속에서 오청하기 쉬운 조합
시각적 혼동: (1↔I↔L), (0↔O↔8), (5↔S), (2↔Z), (6↔G)
→ 데이터 스트립이나 레이더 화면에서 착각하기 쉬운 조합
