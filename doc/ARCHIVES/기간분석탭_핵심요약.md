# 기간 분석 탭 개발 - 핵심 요약 (Executive Summary)

## 📊 현재 상태 vs 요구사항 비교

### 현재 시스템
- ✓ 단일 날짜 필터링
- ✓ 기본 통계 (전체 집계)
- ✓ Sector 기반 분석
- ✓ 시간대 분포 차트

### dev.txt 요구사항
- ❌ 날짜 범위 선택 (시작일~종료일)
- ❌ 일자별 등급 현황 (Stacked Bar Chart)
- ❌ 시간대별 위험 밀도 (Heatmap)
- ❌ 위험 노선 TOP 5 (출발지-도착지)
- ❌ 위험 항공사 조합 TOP 5 (A항공사 vs B항공사)
- ❌ 일자별 상세 테이블
- ❌ 성능 최적화 (3초 내)

---

## 🔴 5가지 Critical Issues

### 1️⃣ 날짜 범위 필터링 부재
**문제:** 단일 날짜만 선택 가능 → 기간 분석 불가
**해결:** SQL에 `WHERE eobd BETWEEN start_date AND end_date` 추가

### 2️⃣ 일자별 집계 데이터 부재
**문제:** 전체 합계만 제공 → 시계열 데이터 없음
**해결:**
- `GROUP BY eobd` 쿼리 추가
- 일자별 {L5, L4, L3} 카운트 반환

### 3️⃣ 노선/항공사 조합 데이터 부재
**문제:** Sector 분석만 있음 → 출발지-도착지 조합 없음
**해결:**
- `dept_airport_cd || '-' || dest_airport_cd` 저장
- `SUBSTR(callsign, 1, 3)` 항공사코드 저장

### 4️⃣ 성능 이슈
**문제:** 기간별 조회 시 JOIN 많음 → 느림
**해결:**
- 역정규화 (이미 계산된 값 저장)
- 인덱스 최적화

### 5️⃣ 데이터베이스 설계 문제
**문제:** `similarities` 테이블에 `eobd` 없음 → 항상 JOIN 필요
**해결:** 컬럼 4개 추가 + 마이그레이션
