# 기간 분석 탭 개발 검토 보고서

## 요약
현재 시스템은 단일 날짜 필터링과 기본 통계 기능을 제공하지만, dev.txt에서 요구하는 **기간(범위) 분석, 상세 시각화, 성능 최적화**를 위해서는 다음과 같은 개선이 필요합니다.

## 1. 주요 문제점 (Critical Issues)

### 1.1 **날짜 범위 필터링 부재**
**현재 상태:**
- 현재는 **단일 날짜** 선택만 가능 (`eobd` 파라미터로 특정 날짜 1개만 필터링)
- `/api/flights/dates`로 사용 가능한 날짜 목록 조회

**문제점:**
- dev.txt 요구사항: "시작일~종료일 선택 (Calendar Picker)"
- 사용자가 7일, 30일 등의 **기간을 설정할 수 없음**
- 기간별 트렌드 분석 불가능

**개선안:**
```
필요한 파라미터 추가:
- start_date (YYYY-MM-DD)
- end_date (YYYY-MM-DD)

SQL 쿼리 수정:
WHERE eobd BETWEEN start_date AND end_date
```

### 1.2 **일자별/시간대별 집계 데이터 부재**
**현재 상태:**
- 전체 통계는 제공하지만, **일자별 세부 집계가 없음**
- Hourly distribution은 있지만 "일자별 등급 현황(Stacked Bar Chart)" 데이터 부재

**문제점:**
- dev.txt 요구사항:
  - "일자별 등급 현황 (Stacked Bar Chart)" → X축: 날짜, Y축: 감지 건수
  - "시간대별 위험 밀도 (Heatmap)" → X축: 요일(월일), Y축: 시간(0-23시)
- 현재는 전체 합계만 제공, 시계열 데이터 부재

**개선안:**
```
새로운 API 응답 구조:

      "00": 3,       // 시간별 건수
      "01": 5,
      ...
    }
  }
}
```

### 1.3 **노선별/항공사 조합별 세부 랭킹 데이터 부재**
**현재 상태:**
- Sector statistics는 있지만, **노선(Route) 기반 통계 없음**
- "항공사 조합" 데이터 없음

**문제점:**
- dev.txt 요구사항:
  - "위험 노선: (출발지-도착지) 조합별 감지 건수 순위"
  - "위험 항공사 조합: (A항공사 vs B항공사) 유사 빈도 순위"
- 현재 `dept_airport_cd`와 `dest_airport_cd`는 저장되지만 집계되지 않음

**개선안:**
```
필요한 집계:
1. Route Statistics:
   SELECT dept_airport_cd, dest_airport_cd, COUNT(*) as count
   FROM similarities s
   JOIN flights f1 ON s.flight_id_1 = f1.id
   WHERE ... GROUP BY 1,2 ORDER BY count DESC LIMIT 5

2. Airline Combination Statistics:
   SELECT
     SUBSTR(s.callsign_1, 1, 3) as airline_1,
     SUBSTR(s.callsign_2, 1, 3) as airline_2,
     COUNT(*) as count
   FROM similarities s
   WHERE ... GROUP BY 1,2 ORDER BY count DESC LIMIT 5
```

### 2.3 **데이터베이스 마이그레이션 전략**

#### Phase 1: 필수 컬럼 추가
```sql
-- 1. similarities 테이블 확장
ALTER TABLE similarities ADD COLUMN eobd DATE;
ALTER TABLE similarities ADD COLUMN route TEXT;  -- "ICN-GMP"
ALTER TABLE similarities ADD COLUMN airline_1 TEXT;  -- "AAR"
ALTER TABLE similarities ADD COLUMN airline_2 TEXT;  -- "DAL"
ALTER TABLE similarities ADD COLUMN peak_hour INTEGER;  -- 0-23

-- 2. 데이터 역산 (마이그레이션 스크립트)
UPDATE similarities
SET
  eobd = (SELECT eobd FROM flights WHERE id = flight_id_1),
  route = (SELECT dept_airport_cd || '-' || dest_airport_cd
           FROM flights WHERE id = flight_id_1),
  airline_1 = SUBSTR(callsign_1, 1, 3),
  airline_2 = SUBSTR(callsign_2, 1, 3),
  peak_hour = CAST(strftime('%H', (
    SELECT entry_time FROM sector_times
    WHERE flight_id = flight_id_1 LIMIT 1
  )) AS INTEGER);

-- 3. 인덱스 추가
CREATE INDEX idx_similarities_eobd_level
  ON similarities(eobd, similarity_level);
CREATE INDEX idx_similarities_route
  ON similarities(route);
CREATE INDEX idx_similarities_airline_combo
  ON similarities(airline_1, airline_2);
CREATE INDEX idx_similarities_peak_hour
  ON similarities(peak_hour);
```

#### Phase 2: 뷰(View) 생성으로 쿼리 단순화
```sql
-- 일자별 집계 뷰
CREATE VIEW v_daily_summary AS
SELECT
  eobd as date,
  COUNT(*) as total_detections,
  SUM(CASE WHEN similarity_level = 'LEVEL_5' THEN 1 ELSE 0 END) as level_5,
  SUM(CASE WHEN similarity_level = 'LEVEL_4' THEN 1 ELSE 0 END) as level_4,
  SUM(CASE WHEN similarity_level = 'LEVEL_3' THEN 1 ELSE 0 END) as level_3,
  ROUND(COUNT(*) * 100.0 / (
    SELECT COUNT(DISTINCT id) FROM flights WHERE eobd = similarities.eobd
  ), 2) as detection_rate
FROM similarities
GROUP BY eobd;

-- 시간별 집계 뷰
CREATE VIEW v_hourly_heatmap AS
SELECT
  eobd as date,
  peak_hour as hour,
  COUNT(*) as detection_count
FROM similarities
WHERE peak_hour IS NOT NULL
GROUP BY eobd, peak_hour;

-- 노선별 집계 뷰
CREATE VIEW v_route_summary AS
SELECT
  route,
  COUNT(*) as count,
  AVG(total_overlap_minutes) as avg_overlap
FROM similarities
WHERE route IS NOT NULL
GROUP BY route
ORDER BY count DESC;
```

### 2.5 **백엔드 로직 개선**

#### 컨텍스트 필터링 엔진 (dev.txt 요구사항)
**현재 상태:**
- 시뮬레이션 시에만 Time Window 필터링 적용
- 통계 조회 시에는 적용 안됨

**요구 사항:**
```
Time Window: EOBT 차이가 ±180분(3시간) 이내인 그룹만 상호 비교
Date Match: EOBD가 동일한 데이터 내에서만 비교 수행
```

**개선안:**
```python
def apply_context_filter(flights, start_date, end_date):
    """
    Period 분석 시 컨텍스트 필터 적용
    - Date Match: EOBD 범위 내만 필터링
    - Time Window: EOBT ±180분 이내만 비교
    """
    # Step 1: Date 범위 필터
    period_flights = [f for f in flights
                      if start_date <= f['eobd'] <= end_date]

    # Step 2: 항공사 접두사(Prefix) 기반 그룹화
    flights_by_prefix = defaultdict(list)
    for f in period_flights:
        prefix = f['callsign'][:3].upper()
        flights_by_prefix[prefix].append(f)

    # Step 3: Time Window 필터링
    comparable_pairs = []
    for prefix, group in flights_by_prefix.items():
        # 같은 항공사 내에서만 비교
        for i, f1 in enumerate(group):
            for f2 in group[i+1:]:
                # ±180분 이내만 포함
                eobt_diff = abs(
                    (f1['eobt'] - f2['eobt']).total_seconds() / 60
                )
                if eobt_diff <= 180:
                    comparable_pairs.append((f1, f2))

    return comparable_pairs
```

### 4.3 **데이터 정합성**
```
⚠️ 주의사항:
1. 마이그레이션 후 similarities.eobd가 NULL일 수 있음
   → 제약조건 추가 전에 모든 데이터 확인

2. 새 항공편 추가 시 트리거 필요
   → 자동으로 route, airline_1, airline_2 계산

CREATE TRIGGER auto_populate_similarity_fields
AFTER INSERT ON similarities
BEGIN
  UPDATE similarities
  SET
    eobd = (SELECT eobd FROM flights WHERE id = NEW.flight_id_1),
    route = (SELECT dept_airport_cd || '-' || dest_airport_cd ...),
    ...
  WHERE id = NEW.id;
END;
```

## 첨부: 상세 SQL 마이그레이션 스크립트

```sql
-- =====================================================
-- 기간분석탭 개발을 위한 DB 마이그레이션 스크립트
-- =====================================================

-- Step 1: similarities 테이블에 필요한 컬럼 추가
BEGIN TRANSACTION;

ALTER TABLE similarities ADD COLUMN eobd DATE DEFAULT NULL;
ALTER TABLE similarities ADD COLUMN route TEXT DEFAULT NULL;
ALTER TABLE similarities ADD COLUMN airline_1 TEXT DEFAULT NULL;
ALTER TABLE similarities ADD COLUMN airline_2 TEXT DEFAULT NULL;
ALTER TABLE similarities ADD COLUMN peak_hour INTEGER DEFAULT NULL;

-- Step 2: 데이터 역산 (마이그레이션)
UPDATE similarities
SET
  eobd = (SELECT eobd FROM flights WHERE id = similarities.flight_id_1),
  route = (
    SELECT dept_airport_cd || '-' || dest_airport_cd
    FROM flights WHERE id = similarities.flight_id_1
  ),
  airline_1 = SUBSTR(similarities.callsign_1, 1, 3),
  airline_2 = SUBSTR(similarities.callsign_2, 1, 3),
  peak_hour = (
    SELECT CAST(strftime('%H', entry_time) AS INTEGER)
    FROM sector_times
    WHERE flight_id = similarities.flight_id_1
    ORDER BY entry_time ASC
    LIMIT 1
  );

-- Step 3: 인덱스 추가
CREATE INDEX IF NOT EXISTS idx_similarities_eobd_level
  ON similarities(eobd DESC, similarity_level);

CREATE INDEX IF NOT EXISTS idx_similarities_route
  ON similarities(route);

CREATE INDEX IF NOT EXISTS idx_similarities_airline_combo
  ON similarities(airline_1, airline_2);

CREATE INDEX IF NOT EXISTS idx_similarities_peak_hour
  ON similarities(peak_hour);

-- Step 4: 고위험 전용 인덱스
CREATE INDEX IF NOT EXISTS idx_similarities_high_risk
  ON similarities(eobd DESC)
  WHERE similarity_level IN ('LEVEL_5', 'LEVEL_4');

COMMIT;

-- =====================================================
-- 뷰(View) 생성
-- =====================================================

-- 일자별 요약
CREATE VIEW IF NOT EXISTS v_daily_summary AS
SELECT
  s.eobd as date,
  COUNT(*) as total_detections,
  SUM(CASE WHEN s.similarity_level = 'LEVEL_5' THEN 1 ELSE 0 END) as level_5,
  SUM(CASE WHEN s.similarity_level = 'LEVEL_4' THEN 1 ELSE 0 END) as level_4,
  SUM(CASE WHEN s.similarity_level = 'LEVEL_3' THEN 1 ELSE 0 END) as level_3,
  COUNT(DISTINCT f.id) as total_flights,
  ROUND(COUNT(*) * 100.0 / COUNT(DISTINCT f.id), 2) as detection_rate
FROM similarities s
JOIN flights f ON s.flight_id_1 = f.id
GROUP BY s.eobd;

-- 시간별 히트맵
CREATE VIEW IF NOT EXISTS v_hourly_heatmap AS
SELECT
  s.eobd as date,
  s.peak_hour as hour,
  COUNT(*) as detection_count
FROM similarities s
WHERE s.peak_hour IS NOT NULL
GROUP BY s.eobd, s.peak_hour;

-- 노선별 요약
CREATE VIEW IF NOT EXISTS v_route_summary AS
SELECT
  s.route,
  COUNT(*) as count,
  AVG(s.total_overlap_minutes) as avg_overlap,
  MAX(s.similarity_score) as max_score
FROM similarities s
WHERE s.route IS NOT NULL
GROUP BY s.route
ORDER BY count DESC;

-- 항공사 조합별 요약
CREATE VIEW IF NOT EXISTS v_airline_combination AS
SELECT
  s.airline_1,
  s.airline_2,
  COUNT(*) as count,
  MAX(s.similarity_score) as max_score
FROM similarities s
WHERE s.airline_1 IS NOT NULL AND s.airline_2 IS NOT NULL
GROUP BY s.airline_1, s.airline_2
ORDER BY count DESC;
```
