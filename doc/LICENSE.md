- 컨설팅 회사

### 포함 내용

- ✓ 소스코드 접근 (선택사항)

## 3. 라이선스 위반 시 조치

### Tier 1: 경고 (30일)
- 통지장 발송
- 위반 중단 요청
- 30일 이내 개선 요청

### Tier 2: 라이선스 정지 (90일)
- 시스템 접근 차단
- 백업 데이터 제공 (14일 기한)
- 법적 조치 고지

### Tier 3: 법적 조치
- 손해배상 청구
- 개발 중단 소송
- 벌금 청구

## 4. 라이선스 검증 프로세스
